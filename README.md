# Katze Version Snapshot

Katze Version Snapshot is a small WordPress admin tool for capturing version information before and after maintenance work.

## Features

- Shows WordPress, PHP, database, theme, and plugin versions in one place
- Renders a Markdown report for copy/paste into tickets or documentation
- Exports the same information as CSV
- Read-only: does not write settings or modify site data

## Usage

1. Install and activate the plugin.
2. Open `Tools > Katze Version Snapshot` in the WordPress admin.
3. Copy the Markdown output or download the CSV snapshot.

## Included Data

- WordPress version
- PHP version
- Database engine and version
- Active theme and parent theme information
- Installed plugin versions and activation status
